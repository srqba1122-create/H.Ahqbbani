# المشروع 1: حساب المضروب (Factorial) بالاستدعاء الذاتي

## الهدف
تتعلم الدالة factorial كيف تستدعي نفسها لحساب حاصل ضرب الأعداد من n حتى 1. حالة التوقف هي n == 0 أو n == 1. استخدمنا long long لاستيعاب نتائج أكبر من int، لكن هذا النوع له حد أقصى أيضًا.

## الكود
يوجد ملف `main.cpp` في هذا المجلد.

## طريقة التشغيل في Visual Studio 2013
1. افتح مشروع **Win32 Console Application**.
2. أنشئ ملف C++ جديدًا أو استبدل محتوى ملف المصدر بالكود الموجود في `main.cpp`.
3. لأن المشروع يستخدم إعدادات Visual Studio 2013 الافتراضية التي تعتمد على Precompiled Header، أبقِ السطر `#include "stdafx.h"` في أعلى الملف. إذا كان مشروعك لا يستخدم Precompiled Header، احذف هذا السطر من الكود.
4. شغّل باستخدام `Ctrl + F5`.
